**Bounded validation job:** `91408071735`

## Batch 2 — Remote-planner redaction and hostile-content boundary

**Implementation commit:** `7963c705b55d23f2ba61726cf9e1bf6ae2ef733a`  
**Bounded validation run:** `30715142209`  
**Bounded validation job:** `91409348721`  
**Result:** success

Implemented:

- Added `src-tauri/src/app_core/planner_redaction.rs` as the mandatory sanitizer before OpenAI- and Ollama-compatible planner serialization.
- Removed all form-control values at live DOM extraction time.
- Replaced arbitrary DOM attribute collection with a strict allowlist.
- Removed DOM locators from remote planner elements because selectors can embed attribute values.
- Removed password, hidden, token-bearing, and similarly sensitive element metadata from the remote view.
- Removed credential references, masked-key metadata, reference errors, pending protected actions, and local model filesystem paths from remote planner context.
- Scrubbed embedded URL credentials, fragments, and common secret-bearing query parameters.
- Bounded page regions, interactive elements, region text, element text, observations, attributes, and skill metadata.
- Sanitized recent tool observations and state summaries before replanning.
- Updated the planner system prompt to label page, OCR, attribute, link, skill, and tool-observation text as untrusted data.
- Removed prompt language that allowed the planner to weaken click confirmation and stated that deterministic runtime policy is authoritative.
- Added regression tests for password/hidden values, unrestricted attributes, selector leakage, secret-bearing URLs, and deterministic payload limits.

Still open within BBCR-003 and BBCR-006:

- Replace the sanitized `PlannerInput` clone with a distinct typed remote-planner payload that cannot represent raw values or unrestricted attributes.
- Add explicit user consent, per-origin remote-data controls, local-only handling, and high-risk-origin behavior.
- Extend redaction policy for payment, identity, healthcare, and other high-risk visible text beyond deterministic key/value markers.
- Add OCR-specific malicious fixtures and a complete hostile-page regression corpus.
- Add injection-warning telemetry that can only increase caution and never authorize action.
- Complete the tracing, diagnostics, UI-error, and remote-response-body leak audit.
